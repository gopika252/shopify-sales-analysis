# Shopify Sales & Customer Analytics

## Project Overview
This project analyses e-commerce transaction data to understand sales performance, product performance, and customer purchasing behaviour. An AI-assisted dashboard was created using Julius AI to visualise business metrics and support data-driven decision-making.

## Business Objectives
- Analyse sales performance and revenue trends.
- Identify top-performing product categories.
- Examine customer purchasing behaviour.
- Compare payment methods and sales by location.
- Develop recommendations based on the observed data.

## Tools Used
- Julius AI — AI-assisted data analysis and visualisation
- Microsoft Excel — dataset inspection and preparation
- Power BI — optional extension for an interactive BI dashboard

## Data Preparation
The dataset was inspected for missing values, duplicate rows, inconsistent text values, and data types. A cleaned portfolio copy was prepared, and direct customer first and last names were removed.

## Dashboard Features
- Sales KPI cards
- Sales trends over time
- Revenue by product type
- Geographic sales analysis
- Payment gateway analysis
- Customer purchasing behaviour

## Key Findings
To be completed using verified results from the dashboard.

1. Running Shoes generated $1,616,946.28, or 35.2% of recorded sales.
2. March 24 was the highest-sales day: $752,227.32 across 1,204 orders.
3. California led billing locations with $535,786.61.
4. 2,039 customers (46.0%) placed at least two orders during the observed week. These customers contributed 67.8% of recorded sales.

## Business Recommendations
Recommendations will be based on the verified findings and the limitations of the available data.

## Limitations
The dataset covers a short period. Long-term customer retention and customer lifetime value cannot be reliably established from a seven-day observation window alone.
